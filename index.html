SimplePath · Next.js + Prisma + Claude API · 2026

Multi-tenant homeschool curriculum platform with an AI teacher parents can audit

  • Live at simplepathhomeschool.com: Pre-K to 12, 117 courses of 180 daily lessons, Stripe billing.
  • One codebase and one database serve several branded schools; every tenant-scoped query injects the tenant.
  • The AI teacher is Socratic on quizzes, budgeted per student and household, and every conversation is visible to the parent.

Designed the product, the tenant and entitlement model, the curriculum structure and the parent-visibility rules; QA of every build. Agents wrote the application code and drafted the lessons under standards guardrails, reviewed before publishing.

TraderIO · Python/FastAPI + C# · 2026

Webhook-to-broker order router with five independent safety gates

  • TradingView alerts in over a Cloudflare tunnel that publishes one path; protected futures orders out through NinjaTrader.
  • Declarative rules and a pure, unit-tested scorer choose which prop-firm account takes each trade.
  • Replaced an n8n flow, then a hosted relay; runs around the clock as a Windows service, 765 tests.

Designed the signal path, the gate model, the rotation rules and the operating procedures; ran it live and turned every incident into a rule. Agents wrote the Python service, the two NinjaScript AddOns and the tests.

LandFinder · Python + PostGIS + Claude API · 2026

County land-opportunity pipeline that uses a model for reading, never for deciding

  • Seven stages from public legal notices to a weekly, reviewable lead list in CSV and Excel.
  • Claude extracts notice fields with a confidence column; scoring, matching and redemption-date math are deterministic and unit-tested.
  • Legal guardrails designed in: throttled, county-scoped, no redistribution, and deed checks left to a person.

Designed the pipeline, the data-source choices and the guardrails. Agents wrote the scrapers, parsers, PostGIS enrichment and reports.

How I work with AI agents

01One source of truth

Generated content may only draw on named primary files. If a claim is not backed there, it does not ship.

02Gate before render

Automated fact checks run on every deliverable before a PDF or document is produced.

03Human review on every output

Agents draft and build; nothing is submitted or sent without my review.

04Direct, don't hand-write

I set architecture and review the agents' work rather than writing each component myself.
