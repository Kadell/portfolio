AI agent builds

Each entry states what I designed and what agents wrote
job-search agents · Claude Code · 2026

Job-search pipeline run on Claude Code agents, with a fact gate on every output

  • Designed a three-stage agent team: a Gmail digest reader, a job qualifier that scores each posting, and a resume customizer for everything above threshold.
  • Strict source rules: one trusted feed, no outside enrichment, no claim that isn't in the resume.
  • Then migrated the process onto the open-source career-ops project, configuring targeting, scoring overrides and house rules.
  • Every generated document is reviewed before it leaves the machine.
I designedThe three-stage pipeline and its source and fact rules; the targeting profile and house rules in career-ops; review of every generated document.
Agents wroteThe pipeline stages and scorer, plus the career-ops customizations and helper scripts. career-ops itself is by Santiago Fernández and its contributors.

Jarvis · voice assistant · 2026

Voice assistant that delegates tasks to Claude Code headless and reads results aloud

  • Runs the whole voice loop locally.
  • Hands real computer work to Claude Code in headless mode.
  • Google Workspace by voice: calendar, Gmail across multiple accounts and send-as aliases, contacts.
  • Everyday tools: weather, traffic-aware directions, local business search, web research and page reading.
  • Voice control of a household to-do board running on a Raspberry Pi.
  • Same assistant from a phone: a PWA talks to a FastAPI endpoint with token auth and continues the conversation started at the desk.
I designedOverall system design and the feature set; research and selection of the speech stack (faster-whisper, Piper, openWakeWord); QA of every build and verification that agent output matched the brief.
Agents wroteEssentially all of the code: voice pipeline, tool registry, Google integrations, builder mode, phone server.

How I work with AI agents

01One source of truth

Generated content may only draw on named primary files. If a claim is not backed there, it does not ship.

02Gate before render

Automated fact checks run on every deliverable before a PDF or document is produced.

03Human review on every output

Agents draft and build; nothing is submitted or sent without my review.

04Direct, don't hand-write

I set architecture and review the agents' work rather than writing each component myself.
